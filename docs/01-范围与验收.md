# 范围与验收

状态说明以 [开发进度表.md](../开发进度表.md) 为准。本文只定义「做什么」和「怎样算做完」。

## 产品目标

第一版只还原 Talking Tom 的核心玩法：听用户说话、变调复读、听/说/闲置/被戳。角色使用自有或可商用卡通猫。全程本地完成，不接对话模型。

## 明确不做

- 不做「教古诗」，不接语音识别、大模型和云端语音合成
- 不使用 Outfit7 官方 Tom 的模型、贴图、音效做开发或发行
- 不做养成、商城、广告
- 不在模拟器上验收录音、变调和回录

## 里程碑出口

未达到出口，不把该里程碑标成已完成，也不开始写下一阶段的功能代码。

| 里程碑 | 出口 |
|---|---|
| M0 准备 | 自己的手机能打开空工程；角色用可商用资源或明确占位 |
| M1 可玩核心 | 真机说一句能变调复读；嘴和声音大致同时结束；播放时不回录；戳身体能打断。六项各连续通过 3 次 |
| M2 手感 | 音高、切句阈值、静音时长、最长句长有一份统一配置；头、肚子、尾巴反应不同。达到后第一版完成 |
