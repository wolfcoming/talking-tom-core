# M1 可玩核心

状态以 [开发进度表](../../开发进度表.md) 为准。方案见 [技术方案](../02-技术方案.md)。

目标：真机上完成一条离线复读。预估 1–2 周。按顺序做，不接语音识别或对话。

## 任务

### 1. 真机上看到角色

- [ ] 角色在画面中，有地面和灯光
- [ ] 麦克风权限已写明用途，真机打开不闪退

交给 AI：

> 给这个 URP 场景加主光和一台对着角色的相机。Android/iOS 加上麦克风权限说明，用途写「把我说的话变调后复读」。不要接语音识别。

### 2. 四个动画状态

- [ ] Idle、Listen、Talk、Poke 能手动切换
- [ ] Talk 结束后回到 Idle

没有动画时用占位：待机轻浮、说话缩放嘴、被戳后仰。

交给 AI：

> 建 Animator Controller：默认 Idle，触发器 Listen、Talk、Poke。Talk 播完回 Idle。没有片段时用简单变换做占位，并给四个按钮。

### 3. 把话切成一句

- [ ] 短句「你好」能在停顿后结束
- [ ] 「今天天气不错」不被切碎
- [ ] 呼吸和远处人声不开始录音

规则先固定：超阈值开始，静音约 700 毫秒结束，最长 8 秒。界面只显示待机、正在听、一句结束和时长。先不播放。用真机。

交给 AI：

> 用 Microphone 录 PCM。能量超过阈值开始，静音 700 毫秒结束，最长 8 秒。界面显示待机、正在听、一句结束和时长。不要变调，不要播回去。

### 4. 变调复读

- [ ] 原句以更高音高复读
- [ ] 播放期间麦克风关闭，无明显啸叫

SoundTouch 只改音高，语速为 1。起步试 +6 到 +8 半音。界面提供滑条。

交给 AI：

> 把一句 PCM 送进 SoundTouch，tempo 保持 1，只升高 pitch，默认 +7 半音，并做滑条。播放前停麦，播完再监听。

### 5. 嘴和声音一起结束

- [ ] Talk 时长和这句话接近
- [ ] 播放时再说的话不会进入下一句

交给 AI：

> 一开始播放就进入 Talk，按音频时长结束并恢复监听。播放期间麦克风必须关闭。

### 6. 戳击打断

- [ ] 复读中途戳身体会停
- [ ] 停下后能听下一句
- [ ] 编辑器鼠标和手机触摸走同一条逻辑

先做一个身体碰撞体。

交给 AI：

> 给身体加 Collider。触摸或鼠标命中时停止复读，播放 Poke，然后回到监听。

## 出口验收

同一部手机，每项连续 3 次。失败时只改对应项，并记录现象、机型、音高、阈值、静音时长。

- [ ] 待机有动作
- [ ] 开口后进入正在听
- [ ] 停顿后变调复读
- [ ] 嘴和声音大致同时结束
- [ ] 播放中说话不会回录
- [ ] 中途戳击能打断
