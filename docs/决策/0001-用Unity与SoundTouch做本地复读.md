# ADR-0001：用 Unity 与 SoundTouch 做本地复读

| 项 | 内容 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-10-27 |
| 替代关系 | 无。若以后改选型，新写 ADR，并把本文件状态改为「已替代」 |

## 背景

第一版只在手机上离线完成核心玩法：听到一句、变调复读、角色有听/说/闲置/被戳。不包含教古诗或云端对话。

## 决策

- 客户端用 Unity 2022.3 LTS 或 Unity 6 LTS（URP）
- 切句用能量门限，复读阶段不做语音识别
- 变调用 SoundTouch，只调整音高
- 角色动作用 Animator；播放时关闭麦克风
- 第一版不做语音识别、大模型和云端合成

## 不选

| 方案 | 原因 |
|---|---|
| Flutter / 纯 Web 作为主工程 | 3D、触摸打断和后续口型更绕 |
| 复读阶段上语音识别 | 增加延迟和联网，不是原版核心 |
| 直接使用官方 Tom 素材 | 版权不属于本项目 |

## 后果

- 需要真机调试音频
- 需要自备可商用角色
- 第一版到 M2 手感打磨结束，没有云端分支
